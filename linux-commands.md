# Linux Commands I Practised
## 1. pwd
- Purpose: Displays the current working directory.
- Example: `pwd`
- ## 2. ls
- Purpose: Lists files and directories.
- Example: `ls`
- ## 3. cd
- Purpose: Changes the current directory.
- Example: `cd Documents`

## 4. mkdir
- Purpose: Creates a new directory.
- Example: `mkdir lab_work`

## 5. touch
- Purpose: Creates an empty file.
- Example: `touch notes.txt`

## 6. chmod
- Purpose: Changes file permissions.
- Example: `chmod u+w notes.txt`

## 7. cat
- Purpose: Displays the contents of a file.
- Example: `cat notes.txt`

## 8. rm
- Purpose: Removes files.
- Example: `rm notes.txt`

## 9. ls -l
- Purpose: Displays files with detailed information, including permissions.
- Example: `ls -l`
