# Git and GitHub Commands

## 1. git init
- Purpose: Initializes a new Git repository in a folder.
- Example: `git init`

## 2. git clone
- Purpose: Downloads a copy of an existing repository.
- Example: `git clone repository-link`

## 3. git status
- Purpose: Shows the current state of files and changes in a repository.
- Example: `git status`

## 4. git add
- Purpose: Adds changes to the staging area before committing.
- Example: `git add README.md`

## 5. git commit
- Purpose: Saves staged changes in the local repository with a message.
- Example: `git commit -m "Add notes"`

## 6. git push
- Purpose: Uploads local commits to a remote repository such as GitHub.
- Example: `git push`

## 7. git pull
- Purpose: Downloads and integrates changes from a remote repository.
- Example: `git pull origin main`

## 8. git log
- Purpose: Displays the history of commits in a repository.
- Example: `git log --oneline`
